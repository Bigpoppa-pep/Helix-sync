# 🧬 HELIX SYNC v2.0

> **Research in Sync · Data in Control**

A fully offline, local-first research utility — runs entirely in your browser. No server, no accounts, no data leaves your device.

---

## ⚠️ Important Disclaimer

**EDUCATIONAL & RESEARCH USE ONLY — NOT MEDICAL EQUIPMENT**

Helix Sync provides arithmetic calculations, record-keeping, and documentation tools only. This software does **not** validate safety, purity, efficacy, or dosing suitability. Never use calculations to guide human administration. All data is stored locally in your browser — export CSVs regularly to backup your work.

---

## ✨ Features

- 🧪 **Concentration Calculator** — Quick arithmetic conversions (mg/mL, mcg/mL, U-100)
- 💉 **Syringe Visualizer** — Schematic volume display with quick sync from calculator
- 📋 **Research Tracker** — Local log with timestamps, categories, and CSV export
- ♥ **BP Lab** — Blood pressure logging and simple trends
- 🥗 **Food & Intake** — Daily tracking with notes
- 🔬 **Evidence Log** — Reference archive for your research sources
- ⏱ **Precision Clock** — Timestamp generator for session documentation
- 🔄 **Cross-Module Sync** — Values auto-feed between linked tools
- 💾 **100% Local** — Everything stays in your browser storage

## 🚀 Quick Start

### Option 1 — Open Directly
1. Download **`helix-sync-v2.html`**
2. Open it in any modern browser (Chrome, Firefox, Edge, Safari, Samsung Internet)
3. That's it — no installation needed!

### Option 2 — Add to Home Screen (Mobile App Feel)
**Android (Chrome / Samsung Internet):**
- Open the file in your browser
- Tap the menu (⋮ or ≡) → **Install app** / **Add to Home screen**
- Name it "Helix Sync" → ✅ Icon appears on your home screen

**iPhone / iPad (Safari):**
- Open the file in Safari
- Tap the Share icon → **Add to Home Screen**
- Name it "Helix Sync" → ✅

## 📂 How It Works

- **Single File** — Everything in one `.html` file. No dependencies.
- **Local Storage** — Your data stays on your device. Use the **Export CSV** buttons regularly to back up your records.
- **Offline Ready** — Once loaded, works completely without internet.
